# Trip Planner

A web app for planning group trips, one place to see who's coming, what still needs bringing and where everyone's supposed to be.

## Project Description

Trip Planner gives a group one shared view of a trip instead of a scattered group chat. Users can see the trips they're part of, claim items from a shared packing list, and follow a day-by-day schedule and see a shared photo gallery.

### User Stories

- As a trip participant, I want to see the schedule grouped by day, so that I know where we're supposed to be and when.
- As a trip participant, I want to be able to create and update a list of items to pack and bring on a trip. If an item is assigned to a user, they should receive a notification that they’ve been designated responsible for bringing said item.
- As a trip participant I want to look into shared photo gallery, able to upload photos, so that we all can look into them, react (like, comment) and share them with other participants.

## Features

- **Shared Photo gallery** — Can upload pictures and react and engage with them.
- **Packing** — Shared to-bring list for one trip. Items have a label and a category and each of them is either claimed by someone or still open. Later down the line you can add an item, claim an open one and release an item you can't do anymore.
- **Itinerary** — Day by day schedule for one trip. Entries would be grouped by day with a time, a place, and a note. They could add, edit and reorder entries.
